A collaborative dictionary game.

About Lexicon

Lexicon is a game in which an arbitrary number of players pretend to be researchers compiling a dictionary, and in the process they will build a world! Players agree on a basic genre to start ("cyberpunk", "fantasy", &c,). In each round every player will choose an existing, undefined word starting with the next letter in alphabetical order or (if there are none) create a new word starting with that letter and write a definition for it. This definition will include two new words that start with later letters (if there are any).

A few ground rules:

  • Do not define a word that you have introduced.
  • Every fact stated in a researcher's bio is canon.
  • Every fact stated in a definition is canon.
  • Opinions, on the other hand, should be frequent and contradictory.
